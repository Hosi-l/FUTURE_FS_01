# Hosaena Belay - Personal Portfolio Website

## 📌 Overview

This is my personal portfolio website created to showcase my skills, projects, education, and journey as a Software Engineering student and aspiring Full Stack Developer.

The goal of this project is to create a professional online presence where recruiters, clients, and developers can learn more about my work.
